# loulouuubirthdayyy 🫶🏼

## Lancer le site
1. Décompresse le ZIP.
2. Ouvre le dossier `loulouuubirthdayyy`.
3. Double-clique sur `index.html`.
4. Clique sur **Ouvrir le cadeau** pour voir la vidéo de famille.
5. Clique sur **Nos souvenirs** pour ouvrir la deuxième page.

## Ajouter les vraies vidéos et photos
Les fichiers personnels ne sont pas inclus : ajoute-les toi-même dans `assets/media/`.

- Vidéo de la famille : `famille.mp4`
- Vidéo de vous deux : `nous.mp4`
- Photos : `photo1.jpg`, `photo2.jpg`, `photo3.jpg`, `photo4.jpg`, `photo5.jpg`, `photo6.jpg`

Les noms doivent correspondre exactement. Tu peux utiliser des photos `.png` aussi, mais dans ce cas change le nom dans `gallery.html` pour qu'il corresponde.

## Personnaliser le compte à rebours
Ouvre `assets/js/script.js` et remplace la date dans `birthdayDate` par la vraie date au format `AAAA-MM-JJTHH:MM:SS`.

## Structure
- `index.html` : page principale + cadeau vidéo
- `gallery.html` : deuxième page avec photos et vidéo de vous deux
- `assets/css/style.css` : design, couleurs et animations
- `assets/js/script.js` : compte à rebours, confettis et cadeau
- `assets/js/gallery.js` : animations de la galerie
- `assets/media/` : ajoute ici tes fichiers personnels
